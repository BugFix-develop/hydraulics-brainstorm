## 1. Физические свойства транспортируемых сред

### 1.1. Плотность и баротермические зависимости капельных жидкостей
Плотность $\rho$ [кг/м³] определяет массу среды в единице объёма. Для нефти и нефтепродуктов плотность зависит от температуры $T$ [°C] и абсолютного давления $p$ [Па]:

$$\rho(p, T) = \rho_{20} \left[ 1 + \xi (20 - T) + \frac{p - p_{\text{атм}}}{K} \right]$$

где:
* $\rho_{20}$ — стандартная плотность при $T = 20^\circ\text{C}$ и $p_{\text{атм}} = 101325\text{ Па}$.
* $\xi$ — температурный коэффициент объёмного расширения [$1/^\circ\text{C}$].
* $K = \frac{1}{\beta}$ — объёмный модуль упругости жидкости [Па], $\beta$ — коэффициент объёмного сжатия [$1/\text{Па}$].

#### Типовые значения плотности и коэффициента $\xi$:
| Нефтепродукт / Среда | $\rho_{20}$ (кг/м³) | $\xi$ ($1/^\circ\text{C}$) | Модуль упругости $K$ (МПа) |
|---|---|---|---|
| Бензины | $700 - 760$ | $0{,}001225 - 0{,}001054$ | $\approx 1000$ ($1{,}0 \cdot 10^9\text{ Па}$) |
| Керосины | $780 - 830$ | $0{,}000995 - 0{,}000882$ | $\approx 1300 - 1500$ |
| Дизельные топлива | $830 - 860$ | $0{,}000882 - 0{,}000782$ | $\approx 1500$ |
| Товарные нефти | $840 - 920$ | $0{,}000831 - 0{,}000688$ | $\approx 1400 - 1600$ |
| Высокосернистые / тяжелые нефти | $900 - 960$ | $0{,}000688 - 0{,}000600$ | $\approx 1600 - 1800$ |
| Вода ($20^\circ\text{C}$) | $998{,}2$ | $0{,}00021$ | $\approx 2060 - 2100$ |

### 1.2. Вязкость жидкостей
Вязкость отражает сопротивление жидкости сдвиговым деформациям (закон Ньютона для трения слоёв: $\tau = \mu \frac{du}{dy}$).

* **Динамическая вязкость** $\mu$ [Па·с] = [Н·с/м²] = [кг/(м·с)].
  *(Внесистемная единица: 1 Пуаз ($\text{П}$) = 0,1 Па·с, 1 сП = $10^{-3}\text{ Па}\cdot\text{с}$)*.
* **Кинематическая вязкость** $\nu$ [м²/с]:
  $$\nu = \frac{\mu}{\rho}$$
  *(Внесистемная единица: 1 Стокс ($\text{Ст}$) = $10^{-4}\text{ м}^2/\text{с}$, 1 сантистокс ($\text{сСт}$) = $1\text{ мм}^2/\text{с} = 10^{-6}\text{ м}^2/\text{с}$)*.

#### Зависимость вязкости от температуры:
1. **Формула Вальтера (ASTM D341)** (стандарт для нефтепродуктов):
   $$\log_{10} \log_{10} (\nu + c) = A - B \log_{10}(T + 273{,}15)$$
   *(где $c \approx 0{,}6 - 0{,}8$, $A, B$ — константы конкретного сорта нефти)*.
2. **Формула Рейнольдса-Филонова**:
   $$\nu(T) = \nu_{20} \cdot e^{-u (T - 20)}$$
   где $u$ — коэффициент температурной чувствительности вязкости ($0{,}02 - 0{,}06\ 1/^\circ\text{C}$).

### 1.3. Физические свойства газов
1. **Уравнение состояния реального газа (Клайперона-Менделеева с фактором сжимаемости):**
   $$p = Z \rho R T \quad \iff \quad \rho = \frac{p}{Z R T}$$
   * $p$ — давление газа [Па].
   * $T$ — абсолютная температура [К].
   * $R = \frac{R_0}{M_{\text{газ}}} = \frac{8314{,}46}{M_{\text{газ}}}$ — газовая постоянная [Дж/(кг·К)].
   * $\Delta = \frac{\rho_{\text{газ}}}{\rho_{\text{возд}}} = \frac{M_{\text{газ}}}{28{,}964}$ — относительная плотность газа по воздуху.
   * $R \approx \frac{287{,}05}{\Delta}$. Для метана/природного газа ($\Delta \approx 0{,}58 - 0{,}65$): $R \approx 440 - 500\text{ Дж/(кг}\cdot\text{К)}$.
   * $Z(p, T)$ — коэффициент сверхсжимаемости газа (безразмерный, $Z \in [0{,}7; 1{,}1]$).
     * Формула Папая: $Z = 1 - 3{,}52 p_{\text{пр}} e^{-2{,}26 T_{\text{пр}}} + 0{,}274 p_{\text{пр}}^2 e^{-1{,}87 T_{\text{пр}}}$, где $p_{\text{пр}} = p / p_{\text{кр}}$, $T_{\text{пр}} = T / T_{\text{кр}}$.
2. **Скорость звука в газе:**
   $$c = \sqrt{\gamma Z R T}$$
   где $\gamma = \frac{C_p}{C_v}$ — показатель адиабаты ($\gamma \approx 1{,}30 - 1{,}34$ для природного газа).

## 2. Фундаментальные уравнения одномерной гидродинамики (Лурье, 2012)

При схематизации течения потока в цилиндрической трубе диаметром $d$ и сечением $S = \frac{\pi d^2}{4}$:

### 2.1. Уравнение неразрывности (сохранения массы)
$$\frac{\partial (\rho S)}{\partial t} + \frac{\partial (\rho v S)}{\partial x} = 0$$

* Для несжимаемой жидкости в жесткой трубе ($\rho = \text{const}, S = \text{const}$):
  $$\frac{\partial v}{\partial x} = 0 \quad \implies \quad Q(t) = v(t) S = \text{const по длине}$$
* Для слабосжимаемой жидкости в упругой трубе:
  $$\frac{\partial p}{\partial t} + \rho c^2 \frac{\partial v}{\partial x} = 0$$
  где $c$ — скорость распространения волн давления.

### 2.2. Уравнение движения (количества движения)
$$\frac{\partial v}{\partial t} + v \frac{\partial v}{\partial x} + \frac{1}{\rho}\frac{\partial p}{\partial x} + g \sin \alpha + \frac{\lambda |v| v}{2 d} = 0$$

где:
* $\sin \alpha = \frac{\partial z}{\partial x}$ — синус угла наклона оси трубы к горизонту ($z$ — геодезическая отметка).
* $\lambda$ — коэффициент гидравлического сопротивления (трения по длине).
* $g = 9{,}80665\text{ м/с}^2$ — ускорение свободного падения.

### 2.3. Уравнение Бернулли (установившееся течение для напорной линии)
Для двух контрольных сечений 1 и 2 трубопровода:

$$z_1 + \frac{p_1}{\rho g} + \frac{\alpha_1 v_1^2}{2g} = z_2 + \frac{p_2}{\rho g} + \frac{\alpha_2 v_2^2}{2g} + h_{1-2}$$

* $H = z + \frac{p}{\rho g}$ — пьезометрический напор [м].
* $H_0 = z + \frac{p}{\rho g} + \frac{\alpha v^2}{2g}$ — полный гидродинамический напор [м].
* $\alpha$ — коэффициент Кориолиса (коррекция кинетической энергии на неравномерность профиля скоростей):
  * $\alpha = 2{,}0$ — для ламинарного (параболического) профиля;
  * $\alpha \approx 1{,}05 - 1{,}1$ — для развитого турбулентного профиля (в инженерных расчетах часто принимают $\alpha \approx 1$).
* $h_{1-2} = h_{\text{тр}} + \sum h_{\text{мест}}$ — суммарные потери напора [м].

## 3. Гидравлические потери на трение по длине трубы

### 3.1. Формула Дарси — Вейсбаха
Потери напора по длине трубы $L$:

$$h_{\text{тр}} = \lambda \frac{L}{d} \frac{v^2}{2g}$$

Потери давления на трение:
$$\Delta p_{\text{тр}} = \rho g h_{\text{тр}} = \lambda \frac{L}{d} \frac{\rho v^2}{2} = \frac{8 \lambda L \rho}{\pi^2 d^5} Q^2$$

Гидравлический уклон:
$$i = \frac{h_{\text{тр}}}{L} = \frac{\lambda}{d} \frac{v^2}{2g} = \frac{8 \lambda}{\pi^2 g d^5} Q^2$$

---

### 3.2. Число Рейнольдса и режимы течения
$$Re = \frac{v d}{\nu} = \frac{4 Q}{\pi d \nu} = \frac{4 M}{\pi d \mu}$$

* **Критическое число:** $Re_{\text{кр}} \approx 2320$.

---

### 3.3. Зоны сопротивления и формулы для коэффициента трения $\lambda$

```
Re < 2320         : Ламинарный режим (Пуазейль)
2320 <= Re < 4000 : Переходная зона
Re >= 4000        : Турбулентный режим, подразделяется на 3 области:
   ├── 4000 <= Re < 10 d/k_e           : Гидравлически гладкие трубы (Блазиус)
   ├── 10 d/k_e <= Re <= 500 d/k_e     : Зона смешанного трения / доквадратичная (Альтшуль)
   └── Re > 500 d/k_e                  : Квадратичная область / автомодельная (Шифринсон)
```

#### 1. Ламинарный режим ($Re < 2320$) — закон Пуазейля:
$$\lambda = \frac{64}{Re}$$
Потери напора строго линейны по расходу:
$$h_{\text{тр}} = \frac{64 \nu}{v d} \frac{L}{d} \frac{v^2}{2g} = \frac{32 \nu L v}{g d^2} = \frac{128 \nu L}{\pi g d^4} Q$$

#### 2. Турбулентный режим в зоне гладких труб ($Re < 10 \frac{d}{k_e}$) — формула Блазиуса:
$$\lambda = \frac{0{,}3164}{Re^{0{,}25}} \quad (\text{при } Re < 10^5)$$
Формула Конакова (для гладких труб при $Re > 10^5$):
$$\lambda = \frac{1}{(1{,}8 \log_{10} Re - 1{,}5)^2}$$

#### 3. Зона смешанной шероховатости ($10 \frac{d}{k_e} \le Re \le 500 \frac{d}{k_e}$):
* **Формула Альтшуля (основная в отечественной практике):**
  $$\lambda = 0{,}11 \left( \frac{k_e}{d} + \frac{68}{Re} \right)^{0{,}25}$$
* **Уравнение Коулбрука — Уайта (международный эталон, неявное):**
  $$\frac{1}{\sqrt{\lambda}} = -2 \log_{10} \left( \frac{k_e}{3{,}7 d} + \frac{2{,}51}{Re \sqrt{\lambda}} \right)$$
* **Формула Свами — Джайна (явное приближение уравнения Коулбрука):**
  $$\lambda = \frac{0{,}25}{\left[ \log_{10} \left( \frac{k_e}{3{,}7 d} + \frac{5{,}74}{Re^{0{,}9}} \right) \right]^2}$$

#### 4. Квадратичная область шероховатых труб ($Re > 500 \frac{d}{k_e}$):
Коэффициент $\lambda$ перестает зависеть от $Re$ (закон автомодельности):
* **Формула Шифринсона:**
  $$\lambda = 0{,}11 \left( \frac{k_e}{d} \right)^{0{,}25}$$
* **Формула Никурадзе:**
  $$\frac{1}{\sqrt{\lambda}} = 2 \log_{10}\left(\frac{d}{2 k_e}\right) + 1{,}74$$

#### Нормативные величины эквивалентной шероховатости $k_e$ (Идельчик, Лурье):
* Новые бесшовные стальные трубы: $k_e = 0{,}02 - 0{,}05\text{ мм}$.
* Трубы магистральных нефтепроводов после нескольких лет эксплуатации: $k_e = 0{,}10 - 0{,}15\text{ мм}$.
* Стальные трубы при коррозии и отложениях: $k_e = 0{,}20 - 0{,}50\text{ мм}$.
* Полиэтиленовые / пластиковые трубы: $k_e = 0{,}005 - 0{,}01\text{ мм}$.

## 4. Местные гидравлические сопротивления (Идельчик, 1992)

Потеря напора на местном сопротивлении:
$$h_{\text{м}} = \zeta \frac{v^2}{2g} \quad \implies \quad \Delta p_{\text{м}} = \zeta \frac{\rho v^2}{2}$$

где $\zeta$ — безразмерный коэффициент местного сопротивления, $v$ — средняя скорость в сечении, к которому отнесён коэффициент $\zeta$.

### 4.1. Основные формулы и типовые коэффициенты $\zeta$:
1. **Внезапное расширение сечения ($S_1 \to S_2$) (теорема Борда — Карно):**
   $$\zeta_{\text{расш}} = \left( 1 - \frac{S_1}{S_2} \right)^2 = \left( 1 - \frac{d_1^2}{d_2^2} \right)^2 \quad (\text{отнесено к } v_1)$$
2. **Внезапное сужение сечения ($S_1 \to S_2$):**
   $$\zeta_{\text{суж}} \approx 0{,}5 \left( 1 - \frac{S_2}{S_1} \right) \quad (\text{отнесено к } v_2)$$
3. **Вход в трубу из резервуара:**
   * С острыми кромками (врезка заподлицо): $\zeta_{\text{вх}} \approx 0{,}5$.
   * С закругленными кромками (коллектор): $\zeta_{\text{вх}} \approx 0{,}05 - 0{,}10$.
   * Труба выступает внутрь резервуара: $\zeta_{\text{вх}} \approx 0{,}8 - 1{,}0$.
4. **Выход из трубы в резервуар больших размеров:**
   $$\zeta_{\text{вых}} = 1{,}0 \quad (\text{кинетическая энергия струи полностью рассеивается})$$
5. **Отводы и колена (поворот потока на угол $\theta$):**
   * Плавный поворот ($R/d \ge 2 - 3$, $\theta = 90^\circ$): $\zeta \approx 0{,}15 - 0{,}25$.
   * Резкое колено без закругления ($\theta = 90^\circ$): $\zeta \approx 1{,}1 - 1{,}3$.
6. **Запорно-регулирующая арматура:**
   * Задвижка клиновая полносборная: полностью открытая $\zeta \approx 0{,}05 - 0{,}15$; открыта на $3/4$: $\zeta \approx 0{,}3 - 0{,}5$; на $1/2$: $\zeta \approx 2{,}0 - 2{,}5$; на $1/4$: $\zeta \approx 15 - 20$.
   * Шаровой кран полнопроходный: $\zeta \approx 0{,}03 - 0{,}05$.
   * Обратный клапан поворотный: $\zeta \approx 1{,}5 - 3{,}0$.

## 5. Законы гидравлических цепей и эквивалентирование

### 5.1. Модуль гидравлического сопротивления ветви
Обобщенная зависимость потерь напора от расхода в ветви:
$$h = s \cdot Q^m$$

где:
* $m = 1$ — ламинарный режим;
* $m = 1{,}75$ — зона гладких труб (Блазиус);
* $m = 2{,}0$ — квадратичная зона (Альтшуль / Шифринсон):
  $$s = \frac{8 \lambda L}{\pi^2 g d^5} + \frac{8 \sum \zeta}{\pi^2 g d^4}$$

### 5.2. Последовательное соединение участков
* Расход постоянен: $Q_1 = Q_2 = \dots = Q$.
* Потери суммируются:
  $$h_{\Sigma} = \sum_{j} h_j = \left( \sum_{j} s_j \right) Q^2 \quad \implies \quad s_{\text{экв}} = \sum_{j} s_j$$

### 5.3. Параллельное соединение участков
* Перепад напора между узлами одинаков: $h_1 = h_2 = \dots = \Delta H$.
* Расходы суммируются: $Q_{\Sigma} = \sum_{k} Q_k$.
* При квадратичном законе ($h_k = s_k Q_k^2 \implies Q_k = \sqrt{\Delta H / s_k}$):
  $$Q_{\Sigma} = \left( \sum_{k} \frac{1}{\sqrt{s_k}} \right) \sqrt{\Delta H} \quad \implies \quad \frac{1}{\sqrt{s_{\text{экв}}}} = \sum_{k} \frac{1}{\sqrt{s_k}}$$

### 5.4. Расчет лупингов
Лупинг — параллельная ветвь той же или иной длины $l_{\text{луп}}$, снижающая гидравлическое сопротивление участка.
Формула потребной длины лупинга диаметра $d_{\text{л}}$ для увеличения расхода трубопровода с $Q_0$ до $Q$ при неизменном доступном напоре:

$$x = \frac{l_{\text{луп}}}{L} = \frac{1 - (Q_0 / Q)^2}{1 - \frac{1}{\left( 1 + (d_{\text{л}} / d)^{2{,}5} \right)^2}}$$

## 6. Насосные станции и совместная работа с трубопроводом

### 6.1. Напорная характеристика насоса ($Q\text{-}H$)
Аппроксимация рабочей характеристики центробежного насоса:
$$H_{\text{н}}(Q) = a - b Q^2 \quad (\text{или } H_{\text{н}} = a - b Q - c Q^2)$$

где $a$ — напор при нулевой подаче (на закрытую задвижку), $b$ — коэффициент крутизны характеристики.

### 6.2. Законы подобия центробежных гидромашин
При изменении частоты вращения ротора с $n_1$ на $n_2$:
$$\frac{Q_2}{Q_1} = \frac{n_2}{n_1}, \qquad \frac{H_2}{H_1} = \left(\frac{n_2}{n_1}\right)^2, \qquad \frac{N_2}{N_1} = \left(\frac{n_2}{n_1}\right)^3$$

При обточке диаметра рабочего колеса с $D_1$ на $D_2$:
$$\frac{Q_2}{Q_1} \approx \frac{D_2}{D_1}, \qquad \frac{H_2}{H_1} \approx \left(\frac{D_2}{D_1}\right)^2$$

### 6.3. Мощность и КПД
* Полезная гидравлическая мощность: $N_{\text{гидр}} = \rho g Q H$ [Вт].
* Потребляемая мощность на валу насоса:
  $$N_{\text{вал}} = \frac{\rho g Q H}{\eta_{\text{н}}}$$
* Потребляемая электрическая мощность электродвигателя:
  $$N_{\text{эл}} = \frac{N_{\text{вал}}}{\eta_{\text{эд}} \cdot \eta_{\text{пер}}} = \frac{\rho g Q H}{\eta_{\text{н}} \eta_{\text{эд}} \eta_{\text{пер}}}$$

### 6.4. Групповое включение насосов
* **Последовательное (напорная станция магистрального трубопровода):**
  $$Q = \text{const}, \qquad H_{\Sigma}(Q) = \sum_{k=1}^m H_k(Q)$$
* **Параллельное (для увеличения подачи):**
  $$H = \text{const}, \qquad Q_{\Sigma}(H) = \sum_{k=1}^m Q_k(H)$$

### 6.5. Определение рабочей точки
Рабочая точка системы «НПС — трубопровод» находится из решения нелинейного уравнения баланса напоров:
$$H_{\text{ст}}(Q) = \Delta z_{\text{геод}} + h_{\text{тр}}(Q) + \sum h_{\text{м}}(Q) + h_{\text{ост}}$$
$$a_{\Sigma} - b_{\Sigma} Q^2 = (z_{\text{кон}} - z_{\text{нач}}) + s_{\text{тр}} Q^2 + h_{\text{ост}}$$

Откуда аналитически:
$$Q_{\text{раб}} = \sqrt{\frac{a_{\Sigma} - (z_{\text{кон}} - z_{\text{нач}}) - h_{\text{ост}}}{b_{\Sigma} + s_{\text{тр}}}}$$

## 7. Неустановившиеся течения и гидравлический удар

### 7.1. Скорость распространения волны давления (формула Жуковского — Кортевега)
$$c = \sqrt{\frac{K / \rho}{1 + \frac{K}{E} \frac{D}{e} \cdot \mu_{\text{зак}}}}$$

где:
* $K$ — объемный модуль упругости жидкости [Па] ($K \approx 1{,}5 \cdot 10^9\text{ Па}$).
* $E$ — модуль Юнга материала стенки трубы [Па] (для трубной стали $E \approx 2{,}06 \cdot 10^{11}\text{ Па}$).
* $D$ — внутренний диаметр трубы [м].
* $e$ — толщина стенки трубы [м].
* $\mu_{\text{зак}}$ — коэффициент закрепления трубы ($\approx 1 - \mu_{\text{сталь}}^2 \approx 0{,}91$ при защемлении концов, либо $\approx 1{,}0$).

**Типовые скорости звука:**
* Вода в стальной трубе: $c \approx 1200 - 1400\text{ м/с}$.
* Нефть / нефтепродукты в стальной трубе: $c \approx 1000 - 1150\text{ м/с}$.
* Природный газ: $c \approx 360 - 420\text{ м/с}$.

### 7.2. Формула Н. Е. Жуковского для прямого гидравлического удара
Прямой гидроудар возникает, если время закрытия задвижки $t_{\text{зак}}$ меньше фазы удара $\tau_{\text{ф}} = \frac{2L}{c}$:

$$\Delta p_{\text{уд}} = \rho c \Delta v \quad \iff \quad \Delta H_{\text{уд}} = \frac{c \Delta v}{g}$$

* Если $t_{\text{зак}} > \tau_{\text{ф}}$ (непрямой гидроудар), максимальный скачок давления приближенно оценивается по формуле Жуковского — Мишо:
  $$\Delta p_{\text{непр}} \approx \Delta p_{\text{уд}} \cdot \frac{\tau_{\text{ф}}}{t_{\text{зак}}} = \rho c \Delta v \frac{2L}{c t_{\text{зак}}} = \frac{2 \rho L \Delta v}{t_{\text{зак}}}$$

### 7.3. Метод характеристик (MOC) для численного расчета переходных процессов
Дифференциальные уравнения переходят в ОДУ вдоль характеристических линий:

$$\frac{dx}{dt} = \pm c$$

* Вдоль $C^+$ ($\frac{dx}{dt} = +c$):
  $$p_i^{t+\Delta t} - p_{i-1}^t + \rho c (v_i^{t+\Delta t} - v_{i-1}^t) + \rho c \left( \frac{\lambda |v| v}{2d} + g \sin \alpha \right)_{i-1} \Delta t = 0$$
* Вдоль $C^-$ ($\frac{dx}{dt} = -c$):
  $$p_i^{t+\Delta t} - p_{i+1}^t - \rho c (v_i^{t+\Delta t} - v_{i+1}^t) - \rho c \left( \frac{\lambda |v| v}{2d} + g \sin \alpha \right)_{i+1} \Delta t = 0$$

Условие устойчивости схемы Куранта — Фридрихса — Леви (CFL):
$$\Delta t \le \frac{\Delta x}{c + |v|} \approx \frac{\Delta x}{c}$$

## 8. Изотермическое установившееся течение газа в магистральных газопроводах

### 8.1. Основное квадратичное уравнение газопровода
Для установившегося течения в горизонтальном участке длиной $L$ и внутренним диаметром $d$:

$$p_{\text{нач}}^2 - p_{\text{кон}}^2 = \frac{16 \lambda Z_{\text{ср}} R T_{\text{ср}} L}{\pi^2 d^5} M^2$$

где:
* $M$ — постоянный массовый расход газа [кг/с].
* Коммерческий (объемный) расход газа $Q_{\text{ком}}$ при стандартных условиях ($p_{\text{ст}} = 101325\text{ Па}$, $T_{\text{ст}} = 293{,}15\text{ К}$):
  $$Q_{\text{ком}} = \frac{M}{\rho_{\text{ст}}} = \frac{Z_{\text{ст}} R T_{\text{ст}}}{p_{\text{ст}}} M$$

### 8.2. Распределение давления по длине газопровода
$$p(x) = \sqrt{p_{\text{нач}}^2 - \left( p_{\text{нач}}^2 - p_{\text{кон}}^2 \right) \frac{x}{L}}$$

> **Важно:** В отличие от капельной жидкости, где эпюра давления вдоль однородной горизонтальной трубы строго линейна, в газопроводе давление падает по **выпуклой вверх параболе** (скорость газа возрастает к концу трубы из-за снижения плотности, что резко увеличивает гидравлический уклон $dp/dx$).

### 8.3. Среднее давление на участке газопровода
$$p_{\text{ср}} = \frac{1}{L} \int_0^L p(x) dx = \frac{2}{3} \left( p_{\text{нач}} + \frac{p_{\text{кон}}^2}{p_{\text{нач}} + p_{\text{кон}}} \right)$$

## 9. Неньютоновские жидкости (реология высоковязких нефтей)

Для высоковязких нефтей с высоким содержанием парафинов и смол ньютоновская модель неприменима при температурах ниже температуры насыщения парафином ($T < T_{\text{нп}}$).

### 9.1. Вязкопластичная жидкость Шведова — Бингама
$$\begin{cases}
\frac{du}{dy} = 0, & \text{при } |\tau| \le \tau_0 \quad (\text{зона твердого псевдостержня ядра потока}) \\
\tau = \tau_0 \operatorname{sign}\left(\frac{du}{dy}\right) + \mu_p \frac{du}{dy}, & \text{при } |\tau| > \tau_0
\end{cases}$$

* $\tau_0$ — динамическое напряжение сдвига (предел текучести) [Па].
* $\mu_p$ — пластическая вязкость [Па·с].

#### Формула Букингема для ламинарного расхода:
$$Q = \frac{\pi d^4 \Delta p}{128 \mu_p L} \left[ 1 - \frac{4}{3}\left(\frac{\tau_0}{\tau_w}\right) + \frac{1}{3}\left(\frac{\tau_0}{\tau_w}\right)^4 \right]$$
где $\tau_w = \frac{\Delta p \cdot d}{4 L}$ — касательное напряжение на стенке трубы.

### 9.2. Число Хедстрёма и Сен-Венана (Илюшина)
Критерии гидродинамического подобия неньютоновских сред:
$$He = \frac{\tau_0 d^2 \rho}{\mu_p^2}, \qquad Il = \frac{\tau_0 d}{\mu_p v}$$

## 11. Назначение для ИИ-агентов (Guidance for Computational Skill)

1. **Валидация физических моделей:**
   Перед гидравлическим расчетом агент обязан проверить $Re$:
   * Если $Re < 2320$ — использовать строгую линейную модель Пуазейля.
   * Если $Re \ge 4000$ — выбирать $\lambda$ по Альтшулю/Свами-Джайну с учетом относительной шероховатости $\frac{k_e}{d}$.
2. **Алгоритмы решения узловых давлений и контурных расходов:**
   * Нелинейность гидравлических цепей $\Delta H = s Q |Q|$ требует применения метода Ньютона — Рафсона или глобального градиентного метода (GGA, Тодини).
3. **Волновые расчеты:**
   * При анализе закрытия отсечной арматуры или аварийной остановки насосов всегда проверять критерий прямого гидроудара по фазе $\tau = \frac{2L}{c}$.
